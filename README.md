# Global Sayar Kontrol

İçerik Motoru ajanlarının 2 boyutlu ofisi, onaylar, raporlar ve videolar — telefona kurulabilen uygulama (PWA).

Bu depo yalnızca uygulama kodunu içerir; hiçbir veri ya da anahtar barındırmaz. Uygulama verileri, kullanıcının
kendi cihazına girdiği ve yalnızca kendi özel deposuna yetkili GitHub anahtarıyla doğrudan GitHub API'den okur.
